# IslandBar

[English version](README.md)

Оригинальное локальное приложение для macOS в стиле Dynamic Island. Оно визуально продолжает вырез MacBook, раскрывается при наведении и не требует аккаунта, подписки или собственного сервера.

## Скачать готовое приложение

[Скачать IslandBar v1.3 для Apple Silicon](https://github.com/Fed0rNV/IslandBar/releases/latest/download/IslandBar-v1.3-macOS-arm64.zip)

## Возможности

- полностью невидимый режим ожидания и раскрытие прямо из физического выреза при наведении;
- компактная музыкальная Live Activity под чёлкой и полный набор инструментов по клику;
- реальные обложки Apple Music и Spotify, плавный прогресс и эквалайзер в цветах текущей обложки;
- плавные прерываемые переходы без внешней обводки и тени;
- файловая полка с drag-and-drop, обратным перетаскиванием, Finder и AirDrop;
- история текста, изображений и файлов из буфера обмена (только в оперативной памяти);
- Pomodoro, обычный таймер и секундомер с уведомлениями;
- календарь и напоминания через системный EventKit;
- локальная камера-зеркало;
- встроенный мини-браузер;
- скорость загрузки/отдачи, Wi‑Fi RSSI и батарея;
- быстрый запуск приложений;
- заметка, закладки, вода, обычный счётчик и отсчёт дней;
- запуск при входе, закрепление островка и настройка поведения наведения.

## Как запустить готовую сборку

1. Распакуйте `IslandBar-macOS-arm64.zip`.
2. Перетащите `IslandBar.app` в папку «Программы» — это особенно важно для надёжного автозапуска.
3. Откройте приложение двойным щелчком.
4. Если macOS предупреждает о неизвестном разработчике: нажмите по приложению правой кнопкой → «Открыть» → «Открыть». Это локальная ad-hoc сборка без платного сертификата Apple.
5. Наведите указатель на вырез или нажмите значок IslandBar в строке меню.

Сборка предназначена для Apple Silicon и macOS 14 или новее. Приложение проверено на MacBook с физической чёлкой.

## Системные разрешения

IslandBar просит разрешения только при использовании соответствующего модуля:

- «Автоматизация» — команды Apple Music и Spotify;
- «Календари» и «Напоминания» — расписание и задачи;
- «Камера» — только локальное зеркало, без записи;
- «Уведомления» — завершение таймеров.

Все данные настроек хранятся в `UserDefaults` на Mac. История буфера обмена не записывается на диск и может быть отключена. Файловая полка хранит пути к файлам, а не создаёт их копии. Встроенный браузер использует стандартное хранилище и кэш `WKWebView`; интернет также нужен для загрузки обложек Spotify.

## Ограничение мультимедиа

Публичный API macOS не позволяет безопасно читать глобальные метаданные «Сейчас играет» у любого приложения. Поэтому полные данные и точное перемещение по треку реализованы для Apple Music и Spotify. Системные кнопки воспроизведения могут управлять браузером, но название и прогресс браузерного трека не гарантируются. Приватные фреймворки macOS намеренно не используются.

## Сборка из исходников

Полный Xcode не нужен. В каталоге проекта выполните:

```sh
zsh build.sh
```

Готовое приложение появится в `dist/IslandBar.app`. Проект не использует сторонние пакеты.

IslandBar не связан с NotchBox или Apple и не использует их код, название, иконки либо графику.
